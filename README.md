# SmartBudget Manager (v1.0)

A simple, automated Excel workbook to track income, record expenses, and enforce budget limits.

## 1. Description
SmartBudget Manager contains three core worksheets:
- **Dashboard**: High-level financial summary (Total Income, Total Expenses, Balance, Alert, Charts).
- **Transactions**: Central ledger to enter all incoming and outgoing cash entries.
- **Categories**: Master table with predefined spending categories (Food, Transport, Rent, Health, Education).

## 2. Prerequisites
- Compatible with Microsoft Excel 2016, 2019, 2021, Microsoft 365, or equivalent spreadsheet software.
- Standard formula support enabled (No macros required).

## 3. Quick Start
1. Open `SmartBudget_Manager.xlsx`.
2. Go to `Dashboard` and set your preferred **Monthly Budget Limit**.
3. Go to `Transactions` and start logging entries (Date, Description, Category, Amount).
4. Return to `Dashboard` to view your updated balance and category charts automatically!
